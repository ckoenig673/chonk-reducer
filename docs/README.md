## Documentation Conventions

- Keep the root README focused on value, installation, safety, and navigation.
- Keep detailed runtime, configuration, and architecture material in `REFERENCE.md`.
- Update documentation with any change to routes, settings, environment variables, filesystem effects, or operator workflows.
- Use only sanitized screenshots captured from demo data.
